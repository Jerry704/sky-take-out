作為軟體開發工程師,需要了解在軟體開發過程中的開發流程， 以及軟體開發過程中涉及到的職位角色，角色的分工、職責， 並熟悉軟體開發中涉及到的三種軟體環境。蒼穹外賣是專為餐飲企業量身訂製的軟體產品，包括系統管理後台和小程式端應用兩部分。其中系統管理後台主要提供給餐飲企業內部員工使用，可以對餐廳的分類、菜色、套餐、訂單、員工等進行管理維護，對餐廳的各類數據進行統計。小程式端主要提供給消費者使用，可在線上瀏覽菜色、新增購物車、下單、付款、催單等。



主要學習重點:

應用層

SpringBoot： 快速建構Spring專案, 採用 "約定優於配置" 的想法, 簡化Spring專案的配置開發。 

SpringMVC：SpringMVC是spring框架的一個模組，springmvc和spring無需透過中間整合層進行整合，可以無縫整合。

Spring Task: 由Spring提供的定時任務框架。

httpclient: 主要實作了對http請求的傳送。

Spring Cache: 由Spring提供的資料快取框架。

JWT: 用於對應用程式上的使用者進行身份驗證的標記。

阿里雲OSS: 物件儲存服務，在專案中主要儲存文件，如圖片等。

Swagger： 可以自動的幫助開發人員產生介面文檔，並對介面進行測試。

POI: 封裝了對Excel表格的常用操作。

WebSocket: 一種通訊網路協議，使客戶端和伺服器之間的資料交換更加簡單，用於專案的來單、催單功能實作。


資料層

MySQL： 關係型資料庫, 本專案的核心業務資料都會採用MySQL進行儲存。

Redis： 基於key-value格式儲存的記憶體資料庫, 存取速度快, 經常使用它做快取。

Mybatis： 本專案持久層將會使用Mybatis開發。

pagehelper: 分頁外掛。

spring data redis: 簡化java程式碼操作Redis的API。


使用工具

git: 版本控制工具, 在團隊協作中, 使用該工具對專案中的程式碼進行管理。

maven: 專案建置工具。

junit：單元測試工具，開發人員功能完成後，需透過junit對功能進行單元測試。

postman: 介面測工具，模擬使用者發起的各類HTTP請求，取得對應的回應結果。
